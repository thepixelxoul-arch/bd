Privacy Policy

How the current Amar Shop preview handles data.

Current Preview Storage

This static preview uses browser local storage for test profile information, orders, favorites, activity and settings. That data stays in the browser unless the user clears it or exports it.

Production Accounts

A production version should document what account data is collected, why it is needed, how long it is retained and how users can exercise applicable privacy rights.

Payments

Payment credentials should not be stored in frontend code. Production payment data should be handled by a verified payment processor using secure server-side integration.

Security

Private API keys, admin credentials and sensitive account data must be protected on a secure backend rather than embedded in public GitHub Pages files.

Contact

Privacy questions can be directed through the Contact or Support pages once production support details are configured.
